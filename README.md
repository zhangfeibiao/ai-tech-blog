## 📁 目录结构约定

```
<topic-name>/
├── README.md        # Markdown 版文章（GitHub 默认渲染）
├── index.html       # HTML 版文章
└── assets/          # 图片与静态资源（SVG 优先，MD 与 HTML 共用）
```

新增一个主题时，按上述结构新建目录，并在本文件的「主题目录」表格中登记一行。
